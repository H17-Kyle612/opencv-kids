# 画像素材

`generated/` の透過PNGは、組み込みの画像生成ツール `image_gen` でこのプロジェクト向けに生成しました。
撮影した顔画像や第三者の素材集は含みません。

- 変身8点：`santa`、`beard`、`antlers`、`red`、`star`、`gift`、`cross`、`wreath`
- ケーキ5段階：`cake_0`（丸ごと）、`cake_1`（3/4）、`cake_2`（1/2）、`cake_3`（1/4）、`cake_4`（空の皿）
- 生成プロンプト：`prompts/accessories.json`、`prompts/cakes.json`

生成したPNGをそのまま保存しています。顔への配置、サイズ調整、光や粒子の演出はOpenCVで実行します。
ニンジン鼻は使用していません。
